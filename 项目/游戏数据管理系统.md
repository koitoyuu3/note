# 游戏数据管理系统

```java
SpringBoot + Mybatis + Redis + MySQL
项目描述：实现游戏系统的玩家身份信息、数据信息存储功能，开发后台管理系统，并且能实现正常的充值、购买礼包功能
主要工作：
1.使用Redis对验证码进行缓存，缓解了高并发环境下频繁访问数据库造成性能下降的问题
2.基于布隆过滤器和空值返回机制缓解 Redis 的穿透问题
3.通过延迟删除+主动更新方案解决数据一致性问题
4.实现限额礼包购买功能，并通过乐观锁解决超卖问题
```

## 介绍

- 这是一个面向高并发场景的游戏数据管理系统，核心功能包括玩家身份信息的保存，游戏数据持久化以及充值购买交易链路及后台管理

- 两个挑战：
  - 高并发场景下的系统的稳定性
  - 交易链路的准确性

## 主要工作

- 使用redis对验证码进行缓存，设置过期时间
- 基于布隆过滤器和空值返回机制缓解Redis穿透的问题，可能存在账号尝试访问存储的情况，账号（用户ID）作为key，可能存在很多非法的情况，需要通过布隆过滤器来过滤，同时也可以用空值返回机制，将不存在的值写入Redis，设置过期时间
- 延迟删除+主动更新解决数据一致性的问题，先删除缓存再更新DB，防止线程A删数据+更新数据的时候线程B又缓存了脏数据
- 实现限额礼包购买功能，通过乐观锁解决超卖问题，通过版本号的机制实现并发功能，用户每次尝试购买的时候会获得商品的版本号，尝试更新数据库商品表字段的时候会比对版本号，版本号一致则更新成功
