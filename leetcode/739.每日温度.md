# 每日温度

```java
给定一个整数数组 temperatures ，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

 

示例 1:

输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]
示例 2:

输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
示例 3:

输入: temperatures = [30,60,90]
输出: [1,1,0]
 

提示：

1 <= temperatures.length <= 105
30 <= temperatures[i] <= 100
```

```java
// 我的思路：单调栈，温度小的入栈，大的出栈记录
// 用了两个栈分别存储温度和对应的索引，事实上可以只存索引
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] ans = new int[temperatures.length];
        Deque<Integer> idxStack = new ArrayDeque<>();
        Deque<Integer> tempStack = new ArrayDeque<>();
        
        idxStack.push(0);
        tempStack.push(temperatures[0]);
        for (int i = 1; i < temperatures.length; i++) {
            while (!tempStack.isEmpty() && temperatures[i] > tempStack.peek()) {
                int idx = idxStack.pop();
                tempStack.pop();
                ans[idx] = i - idx;
            }
            
            idxStack.push(i);
            tempStack.push(temperatures[i]);
        }
        return ans;
    }
}

// 优化后的解
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] ans = new int[temperatures.length];
        Deque<Integer> idxStack = new ArrayDeque<>();
        
        idxStack.push(0);
        for (int i = 1; i < temperatures.length; i++) {
            while (!idxStack.isEmpty() && temperatures[i] > temperatures[idxStack.peek()]) {
                int idx = idxStack.pop();
                ans[idx] = i - idx;
            }
            
            idxStack.push(i);
        }
        return ans;
    }
}
```
