# 柱状图中的最大矩形

```java
给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

 

示例 1:



输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
示例 2：



输入： heights = [2,4]
输出： 4
 

提示：

1 <= heights.length <=105
0 <= heights[i] <= 104
```

- 思路：这题需要找出每个矩形两侧**第一个小于其高度的位置**，每个矩形对应着一个答案

```java
// 解法1：暴力搜索（超时但是是这个思路的最基础体现）
class Solution {
    public int largestRectangleArea(int[] heights) {
        int m = heights.length;
        int ans = 0;
        for (int i = 0; i < m; i++) {
            int left = i;
            int right = i;
            // 暴力搜右边
            while (right < m && heights[right] >= heights[i]) {
                right++;
            }
            // 暴力搜左边
            while (left >= 0 && heights[left] >= heights[i]) {
                left--;
            }
            ans = Math.max(ans, heights[i] * (right - left - 1));
        }
        return ans;
    }
}

// 解法2：用单调栈找到所有需要的位置，用数组存储

// 第一种找法（繁琐，思路和每日温度比较像）
class Solution {
    public int largestRectangleArea(int[] heights) {
        int m = heights.length;
        int[] left = new int[m];
        int[] right = new int[m];

        Deque<Integer> st = new ArrayDeque<>();

        // 从左向右找，先push第一个元素，对于后续每遍历一个元素，都检查该单调栈（会确定多个left数组的值）
        st.push(0);
        for (int i = 1; i < m; i++) {
            while (!st.isEmpty() && heights[i] < heights[st.peek()]) {
                int pop = st.pop();
                left[pop] = i;
            }
            st.push(i);
        }
        // 缺陷在于遍历完之后栈可能非空（left数组还没填完，需要额外处理）
        while (!st.isEmpty()) {
            int pop = st.pop();
            left[pop] = m;
        }

        st.clear();

        st.push(m - 1);
        for (int i = m - 2; i > -1; i--) {
            while (!st.isEmpty() && heights[i] < heights[st.peek()]) {
                int pop = st.pop();
                right[pop] = i;
            }
            st.push(i);
        }
        while (!st.isEmpty()) {
            int pop = st.pop();
            right[pop] = -1;
        }

        int ans = 0;
        for (int i = 0; i < m; i++) {
            ans = Math.max(ans, heights[i] * (left[i] - right[i] - 1));
        }
        return ans;
    }
}

// 第二种找法：简洁易懂（最优解）
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        int[] left = new int[n];
        Deque<Integer> st = new ArrayDeque<>();

        // 每次遍历一个元素，确定该元素对应的left值
        // 这里的left值是指“该元素左边首个满足条件的索引”，和方向无关
        for (int i = 0; i < n; i++) {
            int x = heights[i];
            while (!st.isEmpty() && x <= heights[st.peek()]) {
                st.pop();
            }
            left[i] = st.isEmpty() ? -1 : st.peek();
            st.push(i);
        }

        int[] right = new int[n];
        st.clear();
        for (int i = n - 1; i >= 0; i--) {
            int x = heights[i];
            while (!st.isEmpty() && x <= heights[st.peek()]) {
                st.pop();
            }
            right[i] = st.isEmpty() ? n : st.peek();
            st.push(i);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, heights[i] * (right[i] - left[i] - 1));
        }
        return ans;
    }
}
```
