# 数据流的中位数

```java
中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如 arr = [2,3,4] 的中位数是 3 。
例如 arr = [2,3] 的中位数是 (2 + 3) / 2 = 2.5 。
实现 MedianFinder 类:

MedianFinder() 初始化 MedianFinder 对象。

void addNum(int num) 将数据流中的整数 num 添加到数据结构中。

double findMedian() 返回到目前为止所有元素的中位数。与实际答案相差 10-5 以内的答案将被接受。

示例 1：

输入
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出
[null, null, null, 1.5, null, 2.0]

解释
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr[1, 2, 3]
medianFinder.findMedian(); // return 2.0
提示:

-105 <= num <= 105
在调用 findMedian 之前，数据结构中至少有一个元素
最多 5 * 104 次调用 addNum 和 findMedian
```

```java
// 思路：用优先级队列PriorityQueue来实现堆
// 默认优先级为升序（a-b）
// 找中位数的思路：
// 1.分成两堆，left堆放小的值，right堆放大的值，规定奇数个值时left个数多一个
// 2.题目转化为求maxLeft或(maxLeft + minRight) / 2
// 3.当left.size=right.size，若新来一个小数，给left（A），若新来一个大数，给right，但是此时right多一个，因此right需要把minRight给left（B）
// 4.A操作其实和B操作等价，都可以看作执行一次B操作
// 5.同理，当left.size>right.size，新来一个数，先给left，left再把maxLeft给right
class MedianFinder {
    
    // 小根堆
    private PriorityQueue<Integer> right = new PriorityQueue<>();
    // 大根堆
    private PriorityQueue<Integer> left = new PriorityQueue<>((a, b) -> b - a);

    public MedianFinder() {

    }
    
    public void addNum(int num) {
        if (left.size() == right.size()) {
            right.offer(num);
            int minRight = right.poll();
            left.offer(minRight);
        }
        else {
            left.offer(num);
            int maxLeft = left.poll();
            right.offer(maxLeft);
        }
    }
    
    public double findMedian() {
        if (left.size() == right.size()) {
            return (left.peek() + right.peek()) / 2.0;
        }
        else {
            return (double) left.peek();
        }
    }
}

/**
 * Your MedianFinder object will be instantiated and called as such:
 * MedianFinder obj = new MedianFinder();
 * obj.addNum(num);
 * double param_2 = obj.findMedian();
 */


// 对于PriorityQueue：
// 1.add方法添加失败，抛出IllegalStateException，offer方法添加失败，返回false
// 2.peek只查询数据不弹出数据，poll查询并弹出数据
```
