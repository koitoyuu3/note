# 最小栈

```java
设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

MinStack() 初始化堆栈对象。
void push(int val) 将元素val推入堆栈。
void pop() 删除堆栈顶部的元素。
int top() 获取堆栈顶部的元素。
int getMin() 获取堆栈中的最小元素。
 

示例 1:

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.
 

提示：

-231 <= val <= 231 - 1
pop、top 和 getMin 操作总是在 非空栈 上调用
push, pop, top, and getMin最多被调用 3 * 104 次
```

```java
// 1.思路：开一个栈，每个元素是一个数组，arr[0]为当前val，arr[1]为元素入栈后的最小值
class MinStack {
    // 注意不要使用 Stack 类，因为它继承自 Vector，是同步的，会导致一些性能问题
    private final Deque<int[]> stack = new ArrayDeque<>();

    public MinStack() {
        // 添加一个栈底哨兵，val随便设置，最小值设置为MAX_VALUE
        stack.push(new int[]{0, Integer.MAX_VALUE});
    }
    
    public void push(int val) {
        stack.push(new int[]{val, Math.min(getMin(), val)});
    }
    
    public void pop() {
        stack.pop();
    }
    
    public int top() {
        return stack.peek()[0];
    }
    
    public int getMin() {
        return stack.peek()[1];
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack obj = new MinStack();
 * obj.push(val);
 * obj.pop();
 * int param_3 = obj.top();
 * int param_4 = obj.getMin();
 */


// 思路2.用链表实现
class MinStack {
    static class StackNode {
        StackNode next;
        StackNode prev;
        int val;
        public StackNode(int val) {
            this.val = val;
        }
    }

    private StackNode head;  // 哨兵头节点（不存储实际数据）
    private StackNode tail;  // 始终指向最后一个节点（栈顶）
    private StackNode minNode; // 当前最小值节点

    public MinStack() {
        head = new StackNode(-1);
        tail = head; // 初始时 tail 指向 head（空栈）
        minNode = null;
    }

    public void push(int val) {
        StackNode newNode = new StackNode(val);
        // 将新节点插入到链表尾部（tail 之后）
        tail.next = newNode;
        newNode.prev = tail;
        tail = newNode; // 更新 tail 指向新节点

        // 更新最小值
        if (minNode == null || val <= minNode.val) {
            minNode = newNode;
        }
    }

    public void pop() {
        if (tail == head) {
            return; // 空栈，无需操作
        }
        // 移除尾节点
        int oldVal = tail.val;
        tail = tail.prev;
        tail.next = null;
        // 如果弹出的是最小值节点，需要更新 minNode
        if (oldVal == minNode.val) {
            // 从 head 开始重新查找最小值
            minNode = null;
            StackNode curr = head.next;
            while (curr != null) {
                if (minNode == null || curr.val < minNode.val) {
                    minNode = curr;
                }
                curr = curr.next;
            }
        }
        
    }

    public int top() {
        if (tail == head) {
            throw new IllegalStateException("Stack is empty");
        }
        return tail.val;
    }

    public int getMin() {
        if (minNode == null) {
            throw new IllegalStateException("Stack is empty");
        }
        return minNode.val;
    }
}
```
