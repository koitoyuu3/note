# 括号生成

```java
数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

 

示例 1：

输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
示例 2：

输入：n = 1
输出：["()"]
 

提示：

1 <= n <= 8
```

```java
// 思路：回溯，先右括号（，后左括号），但是这样会存在大量的无效递归
class Solution {
    public List<String> generateParenthesis(int n) {
        char[] arr = new char[n * 2];
        List<String> ans = new ArrayList<>();
        dfs(0, n, n, arr, ans);
        return ans;
    }

    void dfs(int i, int left, int right, char[] arr, List<String> ans) {
        if (left == right && left == 0) {
            ans.add(new String(arr));
            return;
        }
        if (left > right || left < 0 || right < 0) {
            return;
        }

        arr[i] = '(';
        dfs(i + 1, left - 1, right, arr, ans);
        
        arr[i] = ')';
        dfs(i + 1, left, right - 1, arr, ans);

    }
}

// 更优解的回溯
class Solution {
    public List<String> generateParenthesis(int n) {
        char[] arr = new char[n * 2];
        List<String> ans = new ArrayList<>();
        dfs(0, 0, arr, ans, n);
        return ans;
    }

    // open 表示选取右括号（的个数
    void dfs(int i, int open, char[] arr, List<String> ans, int n) {
        if (i == arr.length) {
            ans.add(new String(arr));
            return;
        }

        if (open < n) {
            arr[i] = '(';
            dfs(i + 1, open + 1, arr, ans, n);
        }
        
        if (i - open < open) {
            arr[i] = ')';
            dfs(i + 1, open, arr, ans, n);
        }

    }
}
```
