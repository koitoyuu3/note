# N皇后

```java
按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

n 皇后问题 研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 n ，返回所有不同的 n 皇后问题 的解决方案。

每一种解法包含一个不同的 n 皇后问题 的棋子放置方案，该方案中 'Q' 和 '.' 分别代表了皇后和空位。

 

示例 1：


输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
示例 2：

输入：n = 1
输出：[["Q"]]
 

提示：

1 <= n <= 9
```

```java
/*
思路：排列型回溯
先分析题目，每行每列都只能有一个皇后，那么可以遍历每行，将皇后的列号储存到一个数组中
本质上是在枚举列号的全排列
在此基础上来思考避免出现在一个斜线上的问题
    对于↖方向的格子，行号-列号不变
    对于↗方向的格子，行号+列号不变
    因此可以开两个长度为 2*n-1 的数组来记录每条斜线上是否被占用
*/
class Solution {
    private int n;
    private List<List<String>> ans = new ArrayList<>();

    public List<List<String>> solveNQueens(int n) {
        this.n = n;
        int[] queens = new int[n];
        boolean[] col = new boolean[n];
        boolean[] judge_1 = new boolean[2 * n - 1];
        boolean[] judge_2 = new boolean[2 * n - 1];
        dfs(0, judge_1, judge_2, col, queens);
        return ans;    
    }

    void dfs(int i, boolean[] judge_1, boolean[] judge_2, boolean[] col, int[] queens) {
        if (i == n) {
            List<String> path = new ArrayList<>(n);
            for (int c : queens) {
                char[] row = new char[n];
                // 这个方法将该数组用一个值填充每一个元素
                Arrays.fill(row, '.');
                row[c] = 'Q';
                path.add(new String(row));
            }
            ans.add(path);
            return;
        }

        for (int x = 0; x < n; x++) {
            // 行号 + 列号
            int plus = x + i;

            // 行号 - 列号，为了防止出现负数，全部 +n-1 即可
            int minus = x - i + n - 1;
            if (!col[x] && !judge_1[plus] && !judge_2[minus]) {
                // queen的列号可以直接覆盖，不需要恢复现场
                queens[i] = x;
                col[x] = judge_1[plus] = judge_2[minus] = true;
                dfs(i + 1, judge_1, judge_2, col, queens);

                // 这三个数组需要恢复现场
                col[x] = judge_1[plus] = judge_2[minus] = false;
            }
        }
    }
}
```
