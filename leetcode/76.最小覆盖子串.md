# 最小覆盖子串

```java
给你一个字符串 s 、一个字符串 t 。返回 s 中涵盖 t 所有字符的最小子串。如果 s 中不存在涵盖 t 所有字符的子串，则返回空字符串 "" 。

 

注意：

对于 t 中重复字符，我们寻找的子字符串中该字符数量必须不少于 t 中该字符数量。
如果 s 中存在这样的子串，我们保证它是唯一的答案。
 

示例 1：

输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
示例 2：

输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
示例 3:

输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。
 

提示：

m == s.length
n == t.length
1 <= m, n <= 105
s 和 t 由英文字母组成
 

进阶：你能设计一个在 o(m+n) 时间内解决此问题的算法吗？
```

```java
// 思路一：我的思路，用哈希表来存储t中字母出现的次数
// 并且开一个新的方法来检验子串是否能覆盖t，非常繁琐，开的空间很大
class Solution {
    public String minWindow(String s, String t) {
        if (s.length() < t.length()) return "";

        String minSubstring = s + "a";
        List <Integer> list = new ArrayList <>();

        HashMap <Character, Integer> map = new HashMap <>();

        for (int i = 0; i < t.length(); i++) {
            map.put(t.charAt(i), map.getOrDefault(t.charAt(i), 0) + 1);
        }

        for (int i = 0; i < s.length(); i++) {
            if(map.containsKey(s.charAt(i)))
                list.add(i);
        }

        int right = 0;
        for (int i = 0; i < list.size(); i++) {
            int left = list.get(i); 
            if (i != 0) {
                char leftChar = s.charAt(list.get(i - 1));
                map.put(leftChar, map.get(leftChar) + 1);
                
            }
                
            while (!allMeet(map) && right < s.length()) {
                if(map.containsKey(s.charAt(right))) {
                    map.put(s.charAt(right), map.get(s.charAt(right)) - 1);
                }
                right++;
            }
            if (allMeet(map) && right - left < minSubstring.length()) {
                minSubstring = s.substring(left, right);
            }    
            
        }
        
        if (minSubstring.equals(s + "a")) return "";
        else return minSubstring;

    }

    boolean allMeet (HashMap <Character, Integer> map) {
        for (Integer value : map.values()) {
            if (value > 0) return false;
        }
        return true;
    }
}
```

```java
// 思路二：开一个数组cnt，用来记录子串中包含t的字母个数与t的插值
// 用计数变量less记录未包含完全的字母个数
class Solution {
    public String minWindow(String s, String t) {
        int m = s.length();
        int n = t.length();
        int ansLeft = -1; // 答案的左端点，设计为-1非常巧妙
        int ansRight = m; // 答案的右端点
        int left = 0;  // 遍历的左端点
        int right = 0;  // 遍历的右端点
        int[] cnt = new int[128];
        int less = 0; 
        // 对t进行统计
        for (char c : t.toCharArray()) {
            if(cnt[c] == 0) {
                less++;
            }
            cnt[c]++;
        }

        while (right < m) {
            char c = s.charAt(right);
            cnt[c]--;
            if (cnt[c] == 0) {
                less--;
            }
            
            while (less == 0) {
                if (right - left < ansRight - ansLeft) {
                    ansRight = right;
                    ansLeft = left;
                }
                char x = s.charAt(left);
                if (cnt[x] == 0) {
                    less++;
                }
                cnt[x]++;
                left++;
            }

            right++;
        }

        return ansLeft < 0 ? "" : s.substring(ansLeft, ansRight + 1);
        
    }
}
```

- 比较字符串的长度时可以比较端点的差值，不用刻意算长度
