# 合并K个升序链表

```java
给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

 

示例 1：

输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
示例 2：

输入：lists = []
输出：[]
示例 3：

输入：lists = [[]]
输出：[]
 

提示：

k == lists.length
0 <= k <= 10^4
0 <= lists[i].length <= 500
-10^4 <= lists[i][j] <= 10^4
lists[i] 按 升序 排列
lists[i].length 的总和不超过 10^4
```

```java
// 思路1：暴力遍历两两合并
// 又臭又慢
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists.length == 0) return null;
        if (lists.length == 1) return lists[0];
        ListNode dummy = new ListNode(0);
        ListNode temp = dummy;
        for (int i = 0; i < lists.length; i++) {
            dummy.next = merge2Lists(dummy.next, lists[i]);
        }
        return dummy.next;
    }
    ListNode merge2Lists (ListNode h1, ListNode h2) {
        if (h1 == null || h2 == null) return h1 != null ? h1 : h2;
        ListNode dummy = new ListNode(0);
        ListNode temp = dummy;
        while (h1 != null && h2 != null) {
            if (h1.val <= h2.val) {
                temp.next = h1;
                h1 = h1.next;
            }
            else {
                temp.next = h2;
                h2 = h2.next;
            }
            temp = temp.next;
        }
        temp.next = h1 != null ? h1 : h2;
        return dummy.next;        
    }
}

// 思路2：通过分治 + 递归，将链表两两合并
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        return mergeKLists(lists, 0, lists.length);
    }
    // 重写了这个方法
    ListNode mergeKLists(ListNode[] lists, int i, int j) { // 含i不含j
        int m = j - i;
        if (m == 0) return null;
        if (m == 1) return lists[i];
        ListNode left = mergeKLists(lists, i, i + m / 2);
        ListNode right = mergeKLists(lists, i + m / 2, j);
        return merge2Lists (left, right);
    }

    ListNode merge2Lists (ListNode h1, ListNode h2) {
        if (h1 == null || h2 == null) return h1 != null ? h1 : h2;
        ListNode dummy = new ListNode(0);

    }
    
}
```
