# 最长有效括号

```java
给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 "(()())"。

 

示例 1：

输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
示例 2：

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
示例 3：

输入：s = ""
输出：0
 

提示：

0 <= s.length <= 3 * 104
s[i] 为 '(' 或 ')'
```

```java
// 思路：动态规划，维护数组dp[]，dp[i]为以s[i]结尾的最长有小括号（并非整个数组的最长有效括号）
// 1.若s[i]='(',dp[i]=0;
// 2.若s[i]=')',s[i-1]='(',dp[i]=dp[i-2]+2
// 3.若s[i]=')',s[i-1]=')',dp[i]由三部分构成
// 第一部分：以s[i-1]结尾的最长有效括号，长度为dp[i-1]
// 第二部分：以s[i-1]结尾的最长有效括号前一个字符，必须为'('，否则dp[i]=0。该字符下标为i-dp[i-1]-1
// 第三部分：以i-dp[i-1]-2下标字符结尾的最长有效括号，长度为dp[i-dp[i-1]-2]
// 因此dp[i]=2+dp[i-1]+dp[i-dp[i-1]-2]

// 以上所有情况都要注意边界讨论
class Solution {
    public int longestValidParentheses(String s) {
        char[] arr = s.toCharArray();
        if (s.length() < 2) {
            return 0;
        }
        int ans = 0;
        
        int[] dp = new int[arr.length];
        Arrays.fill(dp, 0);

        for (int i = 0; i < arr.length; i++) {
            char ch = arr[i];
            if (ch == ')' && i - 1 >= 0) {
                if (arr[i - 1] == '(') {
                    dp[i] = 2 + (i - 2 >= 0 ? dp[i - 2] : 0);
                }
                else if (i - dp[i - 1] - 1 >= 0 && arr[i - dp[i - 1] - 1] == '(') {
                    dp[i] = 2 + dp[i - 1] + (i - dp[i - 1] - 2 >= 0 ? dp[i - dp[i - 1] - 2] : 0);
                }
            }
            ans = Math.max(ans, dp[i]);
        }
        return ans;
    }
}

// 思路2.栈
// 维护一个栈，栈中放下标，碰到'('直接放，碰到')'弹栈
// 如果栈为空的时候进入')'，无法弹栈，因此创建栈时向其中push一个-1保持一致性
class Solution {
    public int longestValidParentheses(String s) {
        int ans = 0;
        Deque<Integer> stack = new LinkedList<>();
        stack.push(-1);
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            }
            else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                }
                else {
                    ans = Math.max(ans, i - stack.peek());
                }
            }
        }
        return ans;
    }
}
```
