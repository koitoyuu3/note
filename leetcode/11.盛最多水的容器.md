# 盛最多水的容器

```java
给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明：你不能倾斜容器。

 

示例 1：
输入：[1,8,6,2,5,4,8,3,7]
输出：49 
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。

示例 2：
输入：height = [1,1]
输出：1
 

提示：

n == height.length
2 <= n <= 105
0 <= height[i] <= 104
```

```java
// 这题如果暴力枚举会超时，必须采用双指针
class Solution {
    public int maxArea(int[] height) {
        int maxArea = 0;
        int left = 0;
        int right = height.length - 1;
        while (left != right) {
            int curArea = (right - left) * Math.min(height[left], height[right]);
            maxArea = Math.max(curArea, maxArea);
            if (height[left] <= height[right]) 
                left += 1; 
            else right -= 1;
        }
        return maxArea;
    }
}
```

- 说白了其实是一种贪心，贪心算法的代码是很好实现的，重点在于如何证明思想是正确的。
- 双指针做法：一开始左右指针各在两侧，**每次将对应高度小的那个指针向中间移动**。

```java
证明如下：
如果将对应高度大的指针（例如right）向中间移动，那么right - left（宽）会减小，
而移动后的新容器宽度的高度要么不变（和left对应的高度一样），
要么比left对应的高度还小，因此这种情况下，容量一定会减少
既然这样，left对应的位置就不可能作为容器边界了，可以直接丢弃
```
