# 回文链表

```java
给你一个单链表的头节点 head ，请你判断该链表是否为
回文链表
。如果是，返回 true ；否则，返回 false 。

 

示例 1：


输入：head = [1,2,2,1]
输出：true
示例 2：


输入：head = [1,2]
输出：false
 

提示：

链表中节点数目在范围[1, 105] 内
0 <= Node.val <= 9
 

进阶：你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？
```

```java
// 思路一：存到数组中然后用双指针判断
// 思路二：递归
/*
这是一种通过递归反向遍历链表的思路，非常巧妙
function print_values_in_reverse(ListNode head)
    if head is NOT null
        print_values_in_reverse(head.next)
        print head.val
*/
class Solution {
    private ListNode frontPointer;

    private boolean recursivelyCheck(ListNode currentNode) {
        if (currentNode != null) {
            if (!recursivelyCheck(currentNode.next)) {
                return false;
            }
            if (currentNode.val != frontPointer.val) {
                return false;
            }
            frontPointer = frontPointer.next;
        }
        return true;
    }

    public boolean isPalindrome(ListNode head) {
        frontPointer = head;
        return recursivelyCheck(head);
    }
}

// 虽然空间复杂度还是O(n)，但是这种反向遍历的实现思路是非常值得学习的
```

```java
// 思路三：翻转一半链表
// 可以反转前一半或后一半，可以用快慢指针或直接遍历
class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head.next == null) return true;
        int size = 0;
        ListNode temp = head;
        while (temp != null) {
            temp = temp.next;
            size++;
        }
        int half = size / 2;
        ListNode prev = null;
        ListNode curr = head;

        ListNode left = null;
        ListNode mid = null;
        ListNode right = null;
        
        for (int i = 1; i <= half; i++) {
            if (i == half) {
                left = curr;
                mid = curr.next;
            }
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }

        if (size % 2 == 0) {
            right = mid;
        }
        else {
            right = mid.next;
        }

        while (right != null && left != null) {
            if (right.val != left.val) {
                return false;
            }
            right = right.next;
            left = left.next;
        }
        return true;
    }
}
```
