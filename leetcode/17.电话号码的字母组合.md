# 电话号码的字母组合

```java
给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按 任意顺序 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。



 

示例 1：

输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
示例 2：

输入：digits = ""
输出：[]
示例 3：

输入：digits = "2"
输出：["a","b","c"]
 

提示：

0 <= digits.length <= 4
digits[i] 是范围 ['2', '9'] 的一个数字。
```

```java
// 思路：依然是回溯
// 这题我在做的时候开了StringBuffer，看了更优解之后，感觉没有必要，用char数组记录就可以
class Solution {
    public List<String> letterCombinations(String digits) {
        if (digits.isEmpty()) return List.of();
        char[][] dic = new char[][]{{'0'}, {'0'}, {'a', 'b', 'c'}, 
                    {'d', 'e', 'f'}, {'g', 'h', 'i'}, {'j', 'k', 'l'}, 
                    {'m', 'n', 'o'}, {'p', 'q', 'r', 's'}, {'t', 'u', 'v'}, {'w', 'x', 'y', 'z'}};
        
        List<String> ans = new ArrayList<>();
        StringBuilder str = new StringBuilder(digits.length());
        dfs(0, ans, str, digits, dic);
        return ans;
        
    }

    void dfs(int i, List<String> ans, StringBuilder str, String digits, char[][] dic) {
        if (i == digits.length()) {
            ans.add(new String(str.toString()));
            return;
        }

        for (int k = 0; k < dic[digits.charAt(i) - '0'].length; k++) {
            // 字符-'0'是转化成整形的方法
            str.append(dic[digits.charAt(i) - '0'][k]);
            dfs(i + 1, ans, str, digits, dic);
            str.deleteCharAt(str.length() - 1);
        }
        
    }
}

class Solution {
    private static final String[] MAPPING = new String[]{"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

    private final List<String> ans = new ArrayList<>();
    private char[] digits;
    private char[] path;

    public List<String> letterCombinations(String digits) {
        int n = digits.length();
        if (n == 0) {
            return List.of();
        }
        this.digits = digits.toCharArray();
        path = new char[n]; // 注意 path 长度一开始就是 n，不是空数组
        dfs(0);
        return ans;
    }

    private void dfs(int i) {
        if (i == digits.length) {
            // 字符数组是可以直接转成String的，所以不需要StringBuffer
            ans.add(new String(path));
            return;
        }
        for (char c : MAPPING[digits[i] - '0'].toCharArray()) {
            path[i] = c; // 直接覆盖
            dfs(i + 1);
        }
    }
}
```
