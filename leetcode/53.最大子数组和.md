# 最大子数组和

```java
给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组
是数组中的一个连续部分。

 

示例 1：

输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
示例 2：

输入：nums = [1]
输出：1
示例 3：

输入：nums = [5,4,-1,7,8]
输出：23
 

提示：

1 <= nums.length <= 105
-104 <= nums[i] <= 104
 

进阶：如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的 分治法 求解。
```

```java
// 思路一：前缀和
// 用当前遍历到的位置的前缀和减掉前面的最小前缀和，得到子数组和
// 定义minPreSum来存储最小前缀和，并且每轮更新维护
class Solution {
    public int maxSubArray(int[] nums) {
        int ans = Integer.MIN_VALUE;
        int minPreSum = 0;
        int preSum = 0;
        for (int num : nums) {
            preSum += num;
            int testAns = preSum - minPreSum;
            minPreSum = Math.min(minPreSum, preSum);
            ans = Math.max(ans, testAns);
        }
        return ans;

    }
    
}
// 自己写的时候开了大数组存储每一个前缀和导致超时，实际上完全不需要。
```

```java
// 思路二：动态规划
// 用pre来存储遍历到某元素，以该元素结尾的最大子数组和，仅与前一个元素的pre值有关
// 该元素要么加入，要么丢弃前面的pre值，独立
class Solution {
    public int maxSubArray(int[] nums) {
        int pre = 0;
        int maxAns = nums[0];
        for (int num : nums) {
            pre = Math.max(num, pre + num);
            maxAns = Math.max(pre, maxAns);
        }
        return maxAns;

    }    
}
```
