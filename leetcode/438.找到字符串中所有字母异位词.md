# 找到字符串中所有字母异位词

```java
给定两个字符串 s 和 p，找到 s 中所有 p 的 
异位词
 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

 

示例 1:

输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
 示例 2:

输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
 

提示:

1 <= s.length, p.length <= 3 * 104
s 和 p 仅包含小写字母
```

```java
// 思路：滑动窗口 + 双指针
// 处理异位词的思路和49题差不多，将字母出现的次数在int[26]的数组中记录。
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        int m = s.length();
        int n = p.length();
        int[] m_cnt = new int[26];
        int[] n_cnt = new int[26];
        
        int left = 0;
        int right = 0;
        for (int i = 0; i < n; i++) {
            n_cnt[p.charAt(i) - 'a']++;
        }

        while (right < m) {
            m_cnt[s.charAt(right) - 'a']++;
            while (m_cnt[s.charAt(right) - 'a'] > n_cnt[s.charAt(right) - 'a']) {
                // 这里的比较非常巧妙，如果不是异位词且长度相等，那么一定会存在多余的字符（可能是p中有的字符，也可能是p中没有的）
                // 这个时候就需要移动left来消除这些字符了，一直移动到消除目标多余字符为止
                m_cnt[s.charAt(left) - 'a']--;
                left++;
            }
            if (right - left + 1 == n) ans.add(left);
            right++;
        }
        return ans;
    }
}
```
