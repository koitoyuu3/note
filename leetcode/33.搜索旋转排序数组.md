# 搜索旋转排序数组

```java
整数数组 nums 按升序排列，数组中的值 互不相同 。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,5,6,7] 在下标 3 处经旋转后可能变为 [4,5,6,7,0,1,2] 。

给你 旋转后 的数组 nums 和一个整数 target ，如果 nums 中存在这个目标值 target ，则返回它的下标，否则返回 -1 。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

 

示例 1：

输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
示例 2：

输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
示例 3：

输入：nums = [1], target = 0
输出：-1
 

提示：

1 <= nums.length <= 5000
-104 <= nums[i] <= 104
nums 中的每个值都 独一无二
题目数据保证 nums 在预先未知的某个下标上进行了旋转
-104 <= target <= 104
```

```java
// 思路：通过一次二分查找找到最小值，将数组分成两段
// 对每段进行二分查找，找到目标target
class Solution {
    public int search(int[] nums, int target) {
        int m = nums.length;
        int min_index = 0;
        int left = 0;
        int right = m - 1;
        // 已知最小值在第二段，寻找最小值时，为了逼近最小值但不越过，每次right=mid而不是mid-1；
        // 逼近到最后，left和right都处在第二段单调递增的序列上
        // 最后left的值即为最小值
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < nums[m - 1]) {
                right = mid;
            }
            else {
                left = mid + 1;
            }
        }
        min_index = left;
        
        if (target > nums[m - 1]) {
            return binarySelect(nums, 0, min_index - 1, target);
        }
        else {
            return binarySelect(nums, min_index, m - 1, target);
        }

    }

    int binarySelect(int[] nums, int left, int right, int target) {
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (target < nums[mid]) {
                right = mid - 1;
            }
            else if (target > nums[mid]) {
                left = mid + 1;
            }
            else {
                return mid;
            }
        }
        return -1;
    }
}
```
