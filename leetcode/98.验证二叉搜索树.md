# 验证二叉搜索树

```java
给你一个二叉树的根节点 root ，判断其是否是一个有效的二叉搜索树。

有效 二叉搜索树定义如下：

节点的左
子树
只包含 小于 当前节点的数。
节点的右子树只包含 大于 当前节点的数。
所有左子树和右子树自身必须也是二叉搜索树。
 

示例 1：


输入：root = [2,1,3]
输出：true
示例 2：


输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5 ，但是右子节点的值是 4 。
 

提示：

树中节点数目范围在[1, 104] 内
-231 <= Node.val <= 231 - 1
```

```java
// 思路：三种递归方法
// 1.前序遍历，自顶向下，最顶上初始为最大值和最小值，向下过程中不断更新
class Solution {    
    public boolean isValidBST(TreeNode root) {
        return isValidBST(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    boolean isValidBST(TreeNode root, long left, long right) {
        if (root == null) return true;
        long value = root.val;
        return left < value && value < right && isValidBST(root.left, left, value) && isValidBST(root.right, value, right); 
    }
}

// 2.中序遍历，先左后右
// 维护一个最小值变量pre，不断更新
class Solution {
    long pre = Long.MIN_VALUE;    
    public boolean isValidBST(TreeNode root) {
        if (root == null) return true;
        if (!isValidBST(root.left) || root.val <= pre) return false;
        pre = root.val;
        return isValidBST(root.right);
    }
}

// 3.后序遍历，自底向上（最通用的思想）
// 并没有用boolean类型来判断是否为二叉搜索树
// long[] 定义为一个子树的最小值和一个最大值
class Solution {        
    public boolean isValidBST(TreeNode root) {
        // 判断是否为二叉搜索树：long[0]为MIN_VALUE或long[1]为MAX_VALUE，则不是搜索树
        return getMinMax(root)[0] != Long.MIN_VALUE;
    }

    long[] getMinMax(TreeNode root) {
        // 将空初始化为最大、最小，后续就可以不断更新
        if (root == null) return new long[]{Long.MAX_VALUE, Long.MIN_VALUE};
        long value = root.val;
        long[] left = getMinMax(root.left);
        long[] right = getMinMax(root.right);
        // 此时判断为不是搜索树初始化为最小、最大，后续就无法更新了，将此标志带到栈顶
        if (value <= left[1] || value >= right[0]) return new long[]{Long.MIN_VALUE, Long.MAX_VALUE};

        // 如果满足条件，则说明value小于左子树的最大值，大于左子树的最小值
        // 还需要更新左子树的最小值和右子树的最大值
        return new long[]{Math.min(left[0], value), Math.max(value, right[1])};
    }
}

// 采用Long类型的最值而非Integer类型：防止测试样例中有int的inf或-inf
```
