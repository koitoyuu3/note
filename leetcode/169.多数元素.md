# 多数元素

```java
给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

 

示例 1：

输入：nums = [3,2,3]
输出：3
示例 2：

输入：nums = [2,2,1,1,1,2,2]
输出：2
 

提示：
n == nums.length
1 <= n <= 5 * 104
-109 <= nums[i] <= 109
 

进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。
```

```java
class Solution {
    public int majorityElement(int[] nums) {
        int ans = 0;
        int cnt = 0;
        for (int num : nums) {
            if (cnt == 0) {
                ans = num;
                cnt = 1;
            } else {
                cnt += num == ans ? 1 : -1;
            }
        }
        return ans;
    }
}
// 不限制的话用hashMap很好实现
// 限制空间复杂度：众数思想
// 其他数出现的次数加起来也没有众数多，因此用打擂台的思想来解题
// 假设一开始有一个擂主，计数为1，来一个num如果和它不一样，cnt-1，一样就+1，cnt=0就换人
// 最后的擂主一定就是众数
```
