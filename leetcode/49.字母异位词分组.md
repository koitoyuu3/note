# 字母异位词分组

```
给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

字母异位词 是由重新排列源单词的所有字母得到的一个新单词。

 

示例 1:

输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
示例 2:

输入: strs = [""]
输出: [[""]]
示例 3:

输入: strs = ["a"]
输出: [["a"]]
 

提示：

1 <= strs.length <= 104
0 <= strs[i].length <= 100
strs[i] 仅包含小写字母
```

```java
// 思路一：先对字符串排序，存入哈希表中
// 排序后字母异位词的结果都相同，存入相同的key对应的value中
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for(String str : strs){
            char[] array = str.toCharArray();
            Arrays.sort(array);
            String sortStr = new String(array);
            /* 
            map.getOrDefault(key, defaultObject)：
            如果表中存在key，返回对应的value
            不存在key则返回一个默认值
            */
            List<String> strList = map.getOrDefault(sortStr, new ArrayList<String>());
            strList.add(str);
            map.put(sortStr, strList);
        }
        // 在返回时开一个新的数据结构
        // map.values()：返回所有的值
        return new ArrayList<List<String>>(map.values());
    }
}

// 思路二：统计每个字符串中26个字母的个数，拼接成字符串存到key中，其余和思路一一样
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for(String str : strs){
            int[] counts = new int[26];
            for(int i = 0; i < str.length(); i++){
                counts[str.charAt(i) - 'a']++;
            }
            // 只有StringBuffer才能进行拼接
            StringBuffer sb = new StringBuffer();
            for(int i = 0; i < 26; i++){
                sb.append((char)(i + 'a'));
                sb.append(counts[i]);
            }
            // sb.toString()：转成String类型
            String reStr = sb.toString();
            List<String> strList = map.getOrDefault(reStr, new ArrayList<String>());
            strList.add(str);
            map.put(reStr, strList);
        }
        return new ArrayList<List<String>>(map.values());
    }
}
```
