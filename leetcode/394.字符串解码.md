# 字符串解码

```java
给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: k[encoded_string]，表示其中方括号内部的 encoded_string 正好重复 k 次。注意 k 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 k ，例如不会出现像 3a 或 2[4] 的输入。

 

示例 1：

输入：s = "3[a]2[bc]"
输出："aaabcbc"
示例 2：

输入：s = "3[a2[c]]"
输出："accaccacc"
示例 3：

输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
示例 4：

输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
 

提示：

1 <= s.length <= 30
s 由小写英文字母、数字和方括号 '[]' 组成
s 保证是一个 有效 的输入。
s 中所有整数的取值范围为 [1, 300] 
```

- 这道题的难点在于，如何处理嵌套的括号，如`3[a2[c]]`这样的样例

```java
// 思路：双栈法，分别用数字栈和字符串栈来处理
// 注释以 3[a2[c]] 为样例
class Solution {
    public String decodeString(String s) {
        Deque<Integer> numStack = new ArrayDeque();
        Deque<String> strStack = new ArrayDeque();
        int k = 0;
        // 将当前字符串设为空
        String currentString = "";
        for (char ch : s.toCharArray()) {
            // 处理字符串中倍数的一种手段
            if (Character.isDigit(ch)) {
                k = 10 * k + ch - '0';
            }
            // 搜到左括号时，字符串与倍数均入栈
            else if (ch == '[') {
                numStack.push(k);
                strStack.push(currentString);
                k = 0;
                currentString = "";
            }
            // 搜到右括号时，倍数出栈
            // 【重要】此时currentString当中存的是需要复制的内容，出栈的字符串是复制后的子串前面的内容
            else if (ch == ']') {
                int repeatTimes = numStack.pop();
                StringBuilder temp = new StringBuilder(strStack.pop());
                for (int i = 0; i < repeatTimes; i++) {
                    temp.append(currentString);
                }
                // StringBuilder中先加入出栈的字符串，然后复制currentString，最后currentString更新
                currentString = temp.toString();
            }
            else {
                currentString += ch;
            }
        }
        return currentString;
    }
}
```

- 这道题的双栈法非常巧妙，难点在于每次出栈的字符串并不是需要复制的字符串
- 这道题的细节很多，需要尤其注意
