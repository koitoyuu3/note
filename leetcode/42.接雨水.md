# 接雨水

```java
给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，
计算按此排列的柱子，下雨之后能接多少雨水。

示例 1：

输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 
示例 2：

输入：height = [4,2,0,3,2,5]
输出：9
 

提示：

n == height.length
1 <= n <= 2 * 104
0 <= height[i] <= 105
```

- 解题思路：这种题的关键在于不能被题目给的场景所迷惑，要抛开现象看本质
- 这道题的本质就是算每一列的雨水，不需要考虑别的（甚至可以考虑算每一行的雨水，虽然会超时）

```java
// 解法1：计算每一行的雨水数，这样做会超时，但是不失为一种巧妙的想法
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        if (height.length < 3)  return 0;

        int maxLength = 0;  // 容器的最大高度
        for (int i = 0; i < height.length; i++) {
            maxLength = Math.max(maxLength, height[i]);
        }
        for (int i = 1; i <= maxLength; i++) {
            int left = 0;
            // int right = 1;
            while (height[left] < i) {
                left ++;
                // right ++;
            }

            for (int j = left + 1; j < height.length; j++) {
                if (height[j] >= i) {
                    ans += j - left - 1;
                    left = j;
                }
            }
        }
        return ans;
    }
}
```

```java
// 解法二：遍历每一列，找到每一列左边最高的和右边最高的，计算每一列的雨水量
// 这是最常规最直观的一种思路，但是会超时
// 如果在此基础上，对maxLeft采用动态规划求解，是可以AC的
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        if (height.length < 3)  return 0;

        for (int i = 1; i < height.length; i++) {
            // 找最左边最高的
            int maxLeft = 0;
            for (int j = 0; j < i; j++) {
                maxLeft = Math.max(maxLeft, height[j]);
            }
            // 找最右边最高的
            int maxRight = 0;
            for (int j = i + 1; j < height.length; j++) {
                maxRight = Math.max(maxRight, height[j]);
            }
            int min_max = Math.min(maxLeft, maxRight);
            if (min_max > height[i]) {
                ans += min_max - height[i];
            }
        }
        return ans;
    }
}
```

```java
// 方法三：完全的动态规划
// 在方法二优化了一半的基础上进行完全的优化，开数组记录每一列左右的最大值
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        if (height.length < 3)  return 0;
        int[] maxLeft = new int[height.length];
        int[] maxRight = new int[height.length];
        maxLeft[0] = 0;
        maxRight[height.length - 1] = 0;

        for (int i = 1; i < height.length; i++) {
            maxLeft[i] = Math.max(maxLeft[i - 1], height[i - 1]);
        }

        for (int i = height.length - 2; i > 0; i--) {
            maxRight[i] = Math.max(maxRight[i + 1], height[i + 1]);
        }

        for (int i = 1; i < height.length; i++) {
        
            int min_max = Math.min(maxLeft[i], maxRight[i]);
            if (min_max > height[i]) {
                ans += min_max - height[i];
            }
        }
        return ans;
    }
}
```

```java
// 方法四：双指针
// 其实是方法二的一种延申
// 需要做到在优化left的同时还能优化right
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        if (height.length < 3)  return 0;
        int left = 0;
        int right = height.length - 1;
        
        int maxLeft = height[left];
        int maxRight = height[right];

        left++;
        right--;

        while(left <= right) {
            maxLeft = Math.max(maxLeft, height[left]);
            maxRight = Math.max(maxRight, height[right]);
            if (maxLeft <= maxRight) {
                // 左指针的leftMax比右指针的rightMax矮
                // 说明：左指针的右边至少有一个板子 > 左指针左边所有板子
                // 根据水桶效应，保证了左指针当前列的水量决定权在左边
                // 那么可以计算左指针当前列的水量：左边最大高度-当前列高度
                ans += maxLeft - height[left];
                left++;
            }
            else {
                // 右边同理，此时可以做到左边右边都在算，而不是单一的遍历
                ans += maxRight - height[right];
                right--;
            }
        }
        return ans;
    }
}
```
