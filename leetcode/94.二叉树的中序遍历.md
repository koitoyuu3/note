# 二叉树的中序遍历

```java
给定一个二叉树的根节点 root ，返回 它的 中序 遍历 。

 

示例 1：


输入：root = [1,null,2,3]
输出：[1,3,2]
示例 2：

输入：root = []
输出：[]
示例 3：

输入：root = [1]
输出：[1]
 

提示：

树中节点数目在范围 [0, 100] 内
-100 <= Node.val <= 100
 

进阶: 递归算法很简单，你可以通过迭代算法完成吗？
```

```java
// 思路一：递归
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList <>();
        traversal(ans, root);
        return ans;
    }

    void traversal(List<Integer> ans, TreeNode root) {
        if (root == null) return;
        traversal(ans, root.left);
        ans.add(root.val);
        traversal(ans, root.right);
    }
}
// 递归模板，没什么好说的
```

```java
// 思路二：迭代，实际上是递归的变式
// 递归隐式的维护了一个栈，迭代需要写出这个栈
// 栈模拟的思路本质是进入 + 回溯

/* 两次入栈：
第一次入栈是以当前节点为跟节点的整棵子树入栈
第二次入栈是通过栈遍历该子树，然后展开
中序遍历先递归左子树，那么需要按照右中左的顺序入栈
*/

/* 两次出栈：
第一次出栈是展开前将代表子树的栈顶节点出栈
第二次出栈是展开后栈顶的中节点加入遍历序列
*/
class Solution {
    class Node {
        TreeNode node;
        int flag;

        Node(TreeNode node, int flag) {
            this.node = node;
            this.flag = flag;
        }
    }

    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList <>();
        Deque<Node> stack = new LinkedList<>();
        
        stack.push(new Node(root, 1));
        while (!stack.isEmpty()) {
            Node cur = stack.pop();
            if (cur.node == null) continue;
            if (cur.flag == 1) {  // 右中左入栈
                stack.push(new Node(cur.node.right, 1));
                stack.push(new Node(cur.node, 2));
                stack.push(new Node(cur.node.left, 1));
            }
            else {
                ans.add(cur.node.val);
            }
        }
        return ans;
    }
// 迭代模板，根据遍历顺序修改入栈顺序
}
```
