# 腐烂的橘子

```java
在给定的 m x n 网格 grid 中，每个单元格可以有以下三个值之一：

值 0 代表空单元格；
值 1 代表新鲜橘子；
值 2 代表腐烂的橘子。
每分钟，腐烂的橘子 周围 4 个方向上相邻 的新鲜橘子都会腐烂。

返回 直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 -1 。

 

示例 1：



输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
示例 2：

输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的橘子（第 2 行， 第 0 列）永远不会腐烂，因为腐烂只会发生在 4 个方向上。
示例 3：

输入：grid = [[0,2]]
输出：0
解释：因为 0 分钟时已经没有新鲜橘子了，所以答案就是 0 。
 

提示：

m == grid.length
n == grid[i].length
1 <= m, n <= 10
grid[i][j] 仅为 0、1 或 2
```

```java
// 思路：这题用bfs会方便的多，用队列，思路和二叉树的层序遍历很像
class Solution {

    public int orangesRotting(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        int ans = 0;
        int[][] direction = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        Queue<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    q.add(new int[]{i, j});
                }
            }
        }

        while (!q.isEmpty()) {
            int size = q.size();
            while (size-- > 0) {
                int[] target = q.remove();
                for (int i = 0; i < 4; i++) {
                    int row = target[0] + direction[i][0];
                    int col = target[1] + direction[i][1];
                    if (row < 0 || row >= m || col < 0 || col >= n) continue;
                    if (grid[row][col] == 1) {
                        grid[row][col] = 2;
                        q.add(new int[]{row, col});
                    }
                }
            }
            if(!q.isEmpty()) ans++;
        }

        // 这里可以优化一下
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    return -1;
                }
            }
        }

        return ans;
    }
}

// 优化，维护一个fresh变量，少一个判断循环
class Solution {

    public int orangesRotting(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        int ans = 0;
        int fresh = 0;
        int[][] direction = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        Queue<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    q.add(new int[]{i, j});
                }
                else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        while (fresh > 0 && !q.isEmpty()) {
            ans++;
            int size = q.size();
            while (size-- > 0) {
                int[] target = q.remove();
                for (int i = 0; i < 4; i++) {
                    int row = target[0] + direction[i][0];
                    int col = target[1] + direction[i][1];
                    if (row < 0 || row >= m || col < 0 || col >= n) continue;
                    if (grid[row][col] == 1) {
                        grid[row][col] = 2;
                        q.add(new int[]{row, col});
                        fresh--;
                    }
                }
            }
        }
        return fresh > 0 ? -1 : ans;
    }
}
```
