# 设计模式

## 单例模式

- 单例模式保证一个类仅有一个实例，全局一个访问点（不能通过构造方法创建实例）

- 饿汉式：类加载时就已经初始化了，实现简单，线程安全，但是可能提前占用资源造成浪费

  - 使用final：强制该变量无法被重新赋值，防止在类内部通过反射修改instance，破坏单例唯一性

```java
public class SingleTon() {
    // 私有静态实例，类加载就初始化
    private static final SingleTon instance = new SingleTon();

    // 私有构造方法
    private SingleTon() {}

    // 公共静态方法定义全局访问点
    public static SingleTon getInstance() {
        return instance;
    } 
}
```

- 懒汉式：延迟初始化、节省资源，但是线程不安全，如果有多个线程同时判断instance为null，就会创建多个instance实例

```java
// 线程不安全版
public class SingleTon() {
    private static SingleTon instance;

    private SingleTon() {}

    public static SingleTon getInstance() {
        if (instance == null) {
            instance = new SingleTon();
        }
        return instance;
    }
}
```

- 优化：加synchronized，但是这会无论实例是否创建，所有线程调用getInstance()都要获取锁，即便实例已经创建，这就会导致开销很大

```java
// 线程安全版1
public class SingleTon() {
    private static SingleTon instance;

    private SingleTon() {}

    public static synchronized SingleTon getInstance() {
        if (instance == null) {
            instance = new SingleTon();
        }
        return instance;
    }
}
```

- 优化：双重检查锁
- 双重检查的原因：AB线程同时发现instance为null，A线程先拿到锁创建实例，B线程等待，B线程拿到锁后需要再次检查，此时发现已有实例，就不需要创建新的了。

- 存在问题：jvm创建对象时可能通过指令重排序导致空指针问题

```java
// 线程安全版-双重检查锁
public class SingleTon() {
    private static SingleTon instance;

    private SingleTon() {}

    public static SingleTon getInstance() {
        if (instance == null) {
            synchronized(SingleTon.class) {
                if (instance == null) {
                    instance = new SingleTon();
                }
            }
        }
        return instance;
    }
}
```

- final：通过volatile禁止重排序

```java
// 线程安全版-最终版
public class SingleTon() {
    private static volatile SingleTon instance;

    private SingleTon() {}

    public static SingleTon getInstance() {
        if (instance == null) {
            synchronized(SingleTon.class) {
                if (instance == null) {
                    instance = new SingleTon();
                }
            }
        }
        return instance;
    }
}
```
